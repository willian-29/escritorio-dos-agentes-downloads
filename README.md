# Escritório dos Agentes — downloads

[Abrir a página de downloads](https://escritorio-dos-agentes-downloads.solu-es-indu-0357.chatgpt.site)

Escolha Windows, Mac Apple Silicon ou Mac Intel. Não é necessário entrar no GitHub para baixar.
Os três instaladores e as somas de integridade estão nas versões deste repositório.

A página de downloads aponta para a versão estável mais recente. As prévias das versões são usadas somente
para conferência antes da publicação. O instalador Windows mantém assinatura própria, sem certificado comercial;
o SmartScreen pode continuar mostrando um aviso na primeira instalação.
O aplicativo inclui Node e as artes usadas; Claude Code ou Codex precisam estar instalados, com sua própria conta.
Contas, credenciais e conversas de quem montou o aplicativo não acompanham os arquivos.

Este repositório não contém o código-fonte do aplicativo nem o pacote original de artes. Arte incorporada:
[Modern Interiors, de LimeZu](https://limezu.itch.io/moderninteriors), com os créditos e a licença junto do aplicativo.
Não distribuir o pacote de artes nem suas folhas como recursos separados.

## Conferência dos instaladores

O fluxo público “Conferir instaladores públicos” testa somente os pacotes já publicados: assinatura, instalação,
janela, terminal nativo, atualização com reabertura e preservação dos dados. No Windows também confere a janela
com servidor no WSL e a desinstalação. Os executores são descartáveis, sem contas reais ou certificados importados.
O código-fonte do aplicativo, suas montagens de origem e as artes avulsas permanecem privados.
